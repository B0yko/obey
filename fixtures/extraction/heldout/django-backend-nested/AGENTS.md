# Marigold Orders

Order-management system. `backend/` is a Django 5 project and `frontend/` is a static
admin UI.

## Tooling

- Python is managed with uv (`uv sync`, then `uv run ...`).
  - Do not use `pip` or `python -m pip`.
- Commits
  - Use Conventional Commits (`feat`, `fix`, `docs`, `refactor`, `test`, `chore`).
  - Keep each commit to one logical change.

## Behaviour

- Ask before you delete files.
- If something is unclear, say so instead of guessing.

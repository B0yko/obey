# Cedarline Docs

The documentation for Cedarline, built with VitePress. Pages are Markdown files under
`docs/`. The sidebar is configured in `docs/.vitepress/config.ts`.

## Working rules

| Rule | Why |
|------|-----|
| Use pnpm for all commands; do not use npm or yarn. | The lockfile is `pnpm-lock.yaml`. |
| Do not edit anything in `docs/api/`. | It is generated by `pnpm gen:api`. |
| Name new pages with lowercase words separated by hyphens. | URLs are derived from file names. |
| Do not use raw HTML such as `<div>` or `<font>` in Markdown pages. | It breaks the dark theme. |
| New pages start with a `---` front matter block. | VitePress needs it for the page title. |
| Commit messages start with `docs:`, `site:` or `ci:`. | Release notes are built from them. |
| Keep paragraphs short. | Readers skim. |
| Explain acronyms on first use. | Not everyone knows them. |

## Local preview

```bash
pnpm install
pnpm dev
```

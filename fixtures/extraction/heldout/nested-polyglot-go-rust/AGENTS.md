# Cormorant

Cormorant is a log-shipping agent. The collector is written in Go (`go/`) and the compression
core in Rust (`rust/`). Language-specific rules live in `go/AGENTS.md` and `rust/AGENTS.md`.

## House rules

- 🚫 Do not run `git commit`; the maintainer commits after reviewing.
- 🚫 Never `git push`, not even to a fork.
- 📝 Keep your summary to a few sentences.
- 🧭 Prefer the simplest design that works.

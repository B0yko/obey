# go/

The collector. The entry point is `cmd/cormorant/main.go`, and it is built with
`go build ./cmd/...`.

- ✅ After editing Go files, run `go vet ./...` inside `go/`.
- ✅ Name Go files in lower_snake_case.
- 🚫 `internal/gen/` is generated by `go generate`; don't edit it.
- 🚫 Don't introduce new modules in `go.mod`.

## Layout

- `cmd/` binaries
- `internal/` private packages

# Shared conventions

These conventions are shared by all Brookline repositories and are kept in sync by the
platform team. Repository-specific rules live in each repository's `CLAUDE.md`.

## Python

- New modules under `app/` begin with a one-line module docstring.
- Prefer composition over inheritance.

## Layout

- `app/` application code
- `tests/` pytest suites
- `docs/` this folder

For the repository-level rules, see @CLAUDE.md.

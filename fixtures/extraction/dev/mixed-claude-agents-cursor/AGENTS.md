# Quartzline Admin

Internal admin console (React, TypeScript, Vite). The package manager is pnpm.

## Rules

- Use pnpm only. `npm` and `yarn` are forbidden here.
- Do not use `@ts-ignore`.
- Run `pnpm typecheck` before finishing any change to `.ts` or `.tsx` files.
- A change in `src/api/` needs a test in `tests/api/`.
- Write short, descriptive commit messages.
